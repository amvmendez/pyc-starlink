Conectar con GitHub

Este panel guarda los productos directo en tu repositorio. Para eso necesita un token personal de GitHub (funciona como una contraseña solo para este panel — no se comparte con nadie, se queda guardado únicamente en este celular/navegador).

  1. Abre github.com/settings/personal-access-tokens/new
  2. En "Repository access" elige Only select repositories → selecciona pyc-starlink
  3. En "Permissions" → "Repository permissions" busca Contents y ponlo en Read and write
  4. Toca "Generate token" y copia el código que empieza por github_pat_...
  5. Pégalo abajo (solo lo harás una vez por dispositivo)
